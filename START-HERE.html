Get your hardware ready

  • Your .
  • A USB cable that carries data, not just power. If the board never shows up on your computer, try another cable first.
  • Your S3 board has two USB ports: plug into the one labelled USB, not UART. Otherwise the setup password won't show up later.
  • No driver needed: the talks USB by itself.
  • Your board probably uses a USB-serial chip that needs a driver: CP210x (Silicon Labs) or CH340 (WCH). The chip name is printed next to the USB port.
  • Linux has the CP210x/CH340 drivers built in.
  • This repository, cloned or downloaded — you're probably reading this page from it already.
The classic ESP32 has no prebuilt image, so this guide builds it from source. It's community-contributed and compile-tested; the C3 is the main tested board.

Fill in your secrets (optional)

The build needs a src/secrets.h file. Every value in it is optional: leave the form empty and you'll set WiFi and the admin password on the device itself, which is the recommended way.

🔒 Nothing you type here leaves this page — it isn't saved or sent anywhere. But whatever you put in secrets.h is compiled into the firmware, so don't share that build.

Keep it running

      

    

      
Everything below happens on the dashboard. Risky actions need a press of the physical BOOT button: its LED blinks while a request waits for you.

      

        
You want to…Do this

        
Keep the blocklist freshSet an auto-update URL to the weekly build:
https://github.com/aravindnayani/esp32-network-adblocker/releases/download/blocklist/blocklist.bin
That's the default list — it would replace your “everything” list.

        
Turn blocking off for a bitPause. Up to 15 min per hour needs only the password; longer needs a BOOT press.

        
Block one more siteAdd it under Custom domains.

        
Cut off a deviceBan it. The ban follows its MAC address.

        
Update the firmwareFirmware → OTA update, then press BOOT when the LED blinks.

        
Move to a new WiFiForget WiFi. Your admin password is kept.

        
Recover a lost passwordHold BOOT while plugging it in. This clears WiFi and the admin password and reopens setup (the setup password stays the same).

      

      
Power: a router's USB port works well. Cheap adapters can cause dropouts. A printable case is in hardware/ — keep the antenna end clear.
