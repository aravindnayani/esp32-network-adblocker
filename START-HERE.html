🛡️ C3 AdBlock — Start here

Setup runs in this browser, with a small helper program on your computer doing the USB work: flashing the board and sending it your WiFi and admin password. Install the basics once, start the helper, and the rest happens on this page.

1

Install the basics (in a terminal, once)

1. Open Terminal

Press ⌘ Space, type Terminal, press Return.

2. Check Python

python3 --version

You need 3.9 or newer. If macOS offers to install the command line developer tools, click Install and run the command again (this also installs git). Or install Python from python.org.

3. Get the project and start the helper

git clone https://github.com/aravindnayani/esp32-network-adblocker.git
cd esp32-network-adblocker
python3 start-here.py

Already have the folder? Type cd , drag the folder onto the Terminal window, press Return, then run python3 start-here.py.

Can't install Python? (Chrome or Edge only)
  1. Open the web installer in Chrome or Edge, plug in the board and click ⚡ Connect & Install.
  2. Open Logs & Console and note the setup WiFi password it prints.
  3. From your phone, join the C3-AdBlock-XXXX WiFi with that password. In the page that opens, pick your WiFi, enter its password and choose an admin password.
  4. Then open https://c3adblock.local and follow Finish setting up there.

Keep the terminal running while you go through these steps. Passwords you type here go straight to the board over USB; they aren't saved anywhere.

4

Your WiFi and admin password

The board joins your home WiFi with these. The admin password protects its dashboard (user name admin).

The board only uses 2.4 GHz WiFi. If your router has separate 2.4 and 5 GHz names, pick the 2.4 GHz one. Save the admin password in your password manager.

Fingerprint

Your browser will warn that the connection isn't private. That's expected: the board made its own certificate. Check it shows the fingerprint above, then accept it:

  1. On “Your connection is not private”, click the Not secure badge in the address bar → Certificate details, and compare the SHA-256 fingerprint.
  2. If it matches, close that window and click Advanced → Proceed to c3adblock.local (unsafe).
  1. On “Your connection isn't private”, click Not secure in the address bar → Your connection to this site isn't secure → the certificate icon, and compare the SHA-256 fingerprint.
  2. If it matches, click Advanced → Continue to c3adblock.local (unsafe).
  1. On “Warning: Potential Security Risk Ahead”, click Advanced… → View Certificate, and compare SHA-256 under “Fingerprints”.
  2. If it matches, go back and click Accept the Risk and Continue.
  1. On “This Connection Is Not Private”, click Show Details → view the certificate → Details, and compare SHA-256 under “Fingerprints”.
  2. If it matches, click visit this website → Visit Website. macOS may ask for your login password.

Log in as admin. The dashboard's Finish setting up card walks you through the rest:

  • What to block — ads and trackers are always on; tick social media, gambling, adult content or fake news too.
  • Exceptions — apps that must keep working anyway, like WhatsApp or YouTube.
  • Your router's DNS — so every device on the network uses the ad-blocker.

Page doesn't open? Some Android phones and older Windows versions can't look up .local names: use the IP link instead.

6

Using it and keeping it up to date

  • Daily use: open https://c3adblock.local to see what's blocked per device, pause blocking for a few minutes, block extra sites, add exceptions or cut a device off.
  • Blocklist updates: automatic. After you choose what to block, the board downloads a fresh list every day.
  • Firmware updates: on the dashboard under Firmware — OTA update, choose the new firmware.bin and press the board's BOOT button when its LED blinks. Settings and exceptions are kept.
  • New router or WiFi password: on the dashboard, Forget WiFi, then plug the board into this computer and run start-here.py again.
  • Lost the admin password: hold BOOT while plugging the board in, then run start-here.py again.

You're done with the helper: press Ctrl+C in the terminal and unplug the board. Plug it into your router's USB port or any USB charger near the router.
